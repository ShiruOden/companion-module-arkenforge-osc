# Hotkey reference

All strings the module can send to `/HKEYAPP`, and the Arkenforge hotkey each one triggers (via the profile `arkenforge/companion.rwhk`).

Use the action **Send hotkey** (category, then hotkey) or **Send string** with the value from the first column.
